# Voilà AI Operations Layer

This folder mirrors machine-readable operating procedures for Voilà Floor Care.

Governance authority remains in the cross-system AI Operations Command. Domain files here are executable/reference specifications for Voilà agents and workflows.

## Rules
- No operating agent self-certifies material work.
- Completion requires verifiable target-system state.
- Actions obey AUTONOMOUS / AUTO-WITH-LIMITS / OWNER APPROVAL / PROHIBITED authority levels.
- No Jim's branding or protected franchise IP may appear in independent Voilà outputs.
- Skill changes require versioning and regression review.

## Current skills
- `skills/customer-handover.yaml` — customer handover booklet and marketing-photo extraction.
- `skills/website-change.yaml` — inspect, implement, test, merge and verify material website changes.
- `skills/servicem8-config.yaml` — authenticated ServiceM8 audit/configuration with booking, pricing and evidence controls.
- `skills/quote-deposit-booking.yaml` — quote acceptance, 50% deposit and live-slot-safe booking confirmation.
- `skills/job-closeout.yaml` — job evidence, QA, payment handoff and handover trigger.
- `skills/review-reactivation.yaml` — measured review request and service-appropriate reactivation flow.
